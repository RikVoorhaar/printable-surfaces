Printable Surfaces — Plan

Turn smooth surfaces (sphere, Klein bottle, torus, fruit, …) into printable 3-D objects: parametrize → triangulate → fix & emit STL → build a printability graph (max overhang, full support) → verify with the PrusaSlicer CLI.

Implementation notes
  • uv init --name printable-surfaces --python 3.12, then uv add numpy scipy trimesh numpy-stl matplotlib.
  • Resolved versions: numpy 2.5.4, scipy 1.18.1, trimesh 5.1.1, numpy-stl 4.1.1, matplotlib 3.11.2.
  • Smoke test: all modules import under uv run python. Note numpy-stl's top-level module is stl and has no __version__; import by name, don't rely on a version attr.
  • For later phases: PrusaSlicer CLI is external (not pip-installable). A future phase must verify it via prusa-slicer --version and record its path.
  • Shell gotcha: a stale VIRTUAL_ENV (pointing at an unrelated project) was present; uv run ignores it, but unset it if tooling behaves oddly.
  • STL emission can go through either trimesh or numpy-stl; the triangulation/remeshing phase should pick one as canonical.
